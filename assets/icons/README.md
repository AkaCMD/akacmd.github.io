# SVG icon sources

SVG geometry is downloaded unchanged from the following libraries. CSS controls size and monochrome presentation.

- Brand icons: [Simple Icons](https://github.com/simple-icons/simple-icons), CC0.
- Book, mail, and arrows: [Lucide](https://github.com/lucide-icons/lucide), ISC (includes MIT-licensed Feather derivatives).
- Duck: [Twemoji](https://github.com/jdecked/twemoji), graphics licensed CC BY 4.0; attribution appears in the page footer.

Downloaded 2026-10-11. Full licenses are included beside these assets.
